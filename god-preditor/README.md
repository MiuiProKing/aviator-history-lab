# Aviator CLASSIC · БОГ ХИЩНИК

Отдельная версия по образцу `bog-hishchnik-alert` из коммита `dba9535ae23311309efed0f0597b58adcf284363` нашего LuckyJet-проекта. Исходная страница LuckyJet и главная Aviator Lab сохранены.

Обычный и VIP-анализ, дополнительная меньшая цель, карточки истории, архив с фильтрами 2–1000×, CSV, локальный журнал и общий облачный журнал Aviator Lab. Формулы экспериментальные, перенос на Aviator не подтверждает их точность.

Новые коэффициенты читает существующий облачный сборщик отдельного аккаунта. Эта страница не авторизуется в игре. Время LIVE — получение сборщиком; время начальных снимков неизвестно. Для часов и фильтра дат используется Europe/Kyiv с коррекцией по серверу Supabase.

BeeAI выполняется отдельной функцией `aviator-beeai`, с отдельными таблицами, минутным расписанием и настоящим Gemini. Ответ «Наблюдение» и опоздавшие ответы сохраняются честно. Публичный API разрешает только чтение результата; изменение роли, знаний и паузы требует существующего личного кода BeeAI. Ключ Gemini и игровые сессии в клиент не входят.
