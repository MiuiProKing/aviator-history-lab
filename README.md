# Aviator Lab

Отдельная панель Aviator на Supabase по образцу LuckyJet History Lab. Исходный LuckyJet-сайт не изменён.

LIVE, архив, карточки коэффициентов и предыдущих раундов, цели до 1000× и выше, CSV/JSON и облачный журнал проверки каждые 30 секунд. Формулы экспериментальные и не гарантируют будущий результат.

Для новых раундов работает сборщик на ПК. Страница читает только отдельные таблицы Aviator; игровые сессии и серверные ключи в этот репозиторий не входят.

LIVE-время — фактическое время получения сборщиком с поправкой на часы Supabase. Начальная история без времени не участвует во временных расчётах.
