# Aviator Lab — облачный сборщик

Сайт: https://miuiproking.github.io/aviator-history-lab/

Новые коэффициенты получает `aviator-cloud-collector` в Supabase. ПК и BAT для сбора больше не нужны. Планировщик `aviator-stream-watchdog` восстанавливает работу; следующий приём запускается автоматически после завершения предыдущего воркера. Аренда запрещает параллельные игровые сессии сборщика.

Поток подтверждён совпадением ID и коэффициентов с исходным архивом. Демо и другой поток не используются. Исходный сайт LuckyJet не менялся.

Авторизация находится в Supabase Secrets. В публичном клиенте только ключ anon для чтения; записи в архив и управление воркером закрыты.

LIVE-время — момент получения облачным сборщиком. Начальная история без времени не получает выдуманные даты и исключается из временных моделей. При перезапуске восстановленные исторические коэффициенты сохраняются без придуманного времени. Окно с неполными данными остаётся unknown.

Сохранены экспериментальные формулы, архив карточками, предыдущие раунды, цели до 1000× и выше, CSV/JSON и облачный журнал проверки каждые 30 секунд. Экспериментальные расчёты не гарантируют будущие результаты.
